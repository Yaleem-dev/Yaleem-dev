## 👨‍💻 About Abdulhaleem Saheed-Yusuf

I am **Abdulhaleem Saheed-Yusuf** (also known professionally as **Saheed-Yusuf Abdulhaleem**, **Yaleem**, and **Yaleem-dev**), a software engineer and technology builder based in **Lagos, Nigeria**.
